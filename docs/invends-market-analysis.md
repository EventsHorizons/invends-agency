### Patrones saturados

- “Transformamos / impulsamos / llevamos al siguiente nivel”.  
- Promesas de ROI, ranking o “clientes 24/7” sin matices.  
- IA como eslogan antes que caso de uso.  
- Rankings “top agencias” autopublicados.

### Criterios que sí buscan compradores (fuentes de decisión)

Guías independientes/comerciales 2025–2026 coinciden en:

1. Portafolio con sitios reales abribles.  
2. Alcance escrito (entregables, exclusiones, plazos).  
3. Propiedad de código/dominio/accesos.  
4. Conexión sitio ↔ objetivo de negocio (contacto, lead, venta).  
5. SEO técnico / rendimiento / soporte post-lanzamiento.

## 2. Segmentación fundamentada

### Segmento A — Pyme / estudio / profesional con presencia débil  
*(Ideal justificable)*

| Campo | Contenido |
|-------|-----------|
| Situación | Sitio inexistente, desactualizado o que no explica la oferta |
| Necesidad | Presencia digital comprensible y contactable |
| Motivo de búsqueda | Lanzamiento, cambio de oferta, vergüenza del sitio actual, campaña próxima |
| Dudas | Precio, tiempos, “¿me van a entender?”, propiedad del sitio |
| Criterios de comparación | Claridad de propuesta, química en la conversación, ejemplos de método |
| Servicios Invends | Diseño web, Branding, Desarrollo web, Marketing (landing) |
| Tipo | **Ideal** (alineado a muestras + blog) |

### Segmento B — Equipo que ya invierte en tráfico  
*(Ideal parcial)*

| Campo | Contenido |
|-------|-----------|
| Situación | Pauta o SEO con landing/home genérica |
| Necesidad | Continuidad anuncio–página–contacto |
| Motivo | CPL alto, leads fríos, mensaje inconsistente |
| Dudas | ¿Diseño o marketing? ¿Quién mide? |
| Servicios | Marketing, SEO, Diseño web (landings), Desarrollo |
| Tipo | **Ideal** si aceptan fase acotada |

### Segmento C — Producto / fundador con hipótesis  
*(Hipótesis comercial)*

| Campo | Contenido |
|-------|-----------|
| Situación | Idea o MVP a validar |
| Necesidad | Flujo usable en producción con límites claros |
| Servicios | Aplicaciones, MVP ultra-rápido (MaaS) |
| Tipo | **Hipótesis** — sin casos publicados; comunicar con cautela |

### Segmento D — Operación con deuda técnica o procesos repetidos  
*(Hipótesis)*

| Campo | Contenido |
|-------|-----------|
| Situación | Legacy, copiar-pegar entre herramientas |
| Servicios | Migración y refactorización, Automatización, IA |
| Tipo | **Hipótesis** — capacidad listada; evidencia de cliente no publicada |

**No se asignan** edades, ingresos ni sectores prioritarios sin datos.

## 3. Escenarios de decisión (journey)

| Escenario (investigación, no “clientes actuales”) | Qué necesita encontrar | Mensaje Invends |
|---------------------------------------------------|------------------------|-----------------|
| Crear primera presencia | Qué hacen, cómo empiezan, costo/alcance en conversación | Claridad de oferta + “no hace falta tenerlo todo definido” |
| Rediseñar sitio que no representa | Método, ejemplos de estructura/mensaje | Presencia que se entiende; brief antes que píxeles |
| Landing para campaña | Continuidad mensaje–destino | Marketing + diseño de destino |
| Visibilidad orgánica | Honestidad SEO (sin ranking garantizado) | SEO técnico/contenido con límites explícitos |
| Validar producto | Alcance MVP / exclusiones | MVP con límites claros |
| Modernizar sistema | Enfoque por fases | Migración sin apagar operación |
