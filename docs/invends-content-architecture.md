## Orden narrativo del recorrido

1. Comprensión inmediata (hero).  
2. Relevancia (intro reel / escenarios).  
3. Capacidades (pilares + servicios).  
4. Servicios detallados.  
5. Evidencia (muestras + blog).  
6. Manera de trabajar (método / nosotros).  
7. Conversación (contacto / form).
