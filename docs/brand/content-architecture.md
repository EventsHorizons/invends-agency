# Content Architecture — Invends

## Matriz de mensajes (una función por zona)

| Página / sección | Pregunta del visitante | Mensaje principal | No repetir |
|------------------|------------------------|-------------------|------------|
| Home hero | ¿Quiénes son? | Ideas en forma + oficios | Alcance (solo 1 mención en support) |
| Reel intro | ¿Puedo llegar sin brief? | Se puede empezar sin todo definido | Empatía vacía |
| Pilares | ¿Cómo piensan? | Pantalla / Base / Mensaje | Listar 11 servicios |
| Método | ¿Cómo deciden? | Claridad · Oficio · Alcance | Re-explicar hero |
| Muestras | ¿Cómo se ve el trabajo? | Método, no casos cliente | “Experiencias” ambiguas |
| Form | ¿Cómo empiezo? | Notas + alcance | Segundo manifiesto |
| Servicios hub | ¿Qué hay? | Once oficios; elige fase | “Dirección clara” genérica |
| Servicio slug | ¿Esto es para mí? | Headline corto + cuándo aplica + entregables | Copy idéntico entre slugs |
| Portafolio | ¿Puedo confiar? | Muestras de método | Fake results |
| Nosotros | ¿Quién hay detrás? | Forma clara + principios | Bio inventada |
| Contacto | ¿Qué envío? | La necesidad; respondemos con alcance | Plazos inventados |
| Blog | ¿Aprendo algo? | Notas útiles | CTA en cada párrafo |

## Homepage narrative

1. Identidad (hero)  
2. Permiso de entrada (sin brief)  
3. Tres oficios  
4. Criterios de decisión  
5. Evidencia de método  
6. Conversación  

## SEO (cualitativo)

Intent: agencia diseño web / desarrollo / marketing Bogotá.  
Títulos protegidos intactos.  
Metas: naturales, con “forma clara” solo donde no force keyword stuffing.
