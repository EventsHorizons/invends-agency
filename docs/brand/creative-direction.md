# Creative Direction — Invends

## Concepto narrativo

**Forma clara** = dar cuerpo visible a una oferta (pantalla, código, mensaje) sin ruido.

Campo semántico: forma, claridad, estructura, alcance, oficio, fase, oferta, criterio, base, destino.

Ideas recurrentes (una función por zona):

| Zona | Función del concepto |
|------|----------------------|
| Hero | Identidad (“Ideas en forma”) |
| Oficios | Cómo se materializa (pantalla / base / mensaje) |
| Método | Cómo se decide (claridad, oficio, alcance) |
| Servicios | Aplicación específica por necesidad |
| Portafolio | Forma visible del criterio (muestras) |
| Contacto | Empezar a dar forma al alcance |

## Relación verbal ↔ visual

- Titulares cortos sobre plano oscuro (ya presente).  
- Acento itálico en la palabra de concepto (`forma`).  
- Evitar relleno tipográfico; el espacio es parte del ritmo.  
- No añadir badges ni claims flotantes.

## Español / EN

- ES: tú cordial, CO/LATAM, sin voseo.  
- EN: adaptación de sentido (`Clear form.` / `Ideas in form.`), no calco.

## Límites creativos

No filosofar en cada tarjeta.  
No tres palabras vacías.  
No “escuchamos/acompañamos” como estribillo.
