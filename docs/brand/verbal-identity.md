# Verbal Identity — Invends

## Voz

Precisa, editorial, cercana sin sentimentalismo. Piensa en público; escribe como oficio.

## Longitudes

| Elemento | Guía |
|----------|------|
| H1 | 2–7 palabras, una idea |
| Sección | 2–5 palabras |
| Botón | 2–4 palabras |
| Subtítulo | 1 frase nueva |
| Párrafo | Solo si aporta dato |

## Preferir

forma, claridad, alcance, oficio, estructura, fase, oferta, criterio, base, destino, usable

## Evitar / limitar

transformamos, impulsamos, potenciamos, extraordinario, líder, garantizado, aliado estratégico; abuso de escuchamos / acompañamos / juntos / experiencias digitales
