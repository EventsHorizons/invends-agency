# 03. MAPA DE PALABRAS CLAVE: INVESTIGACIÓN, INTENCIÓN Y ARQUITECTURA
## Estrategia Semántica para Invends en Bogotá, Colombia y Mercados Hispanohablantes

**Fecha:** Noviembre 2026  
**Fuentes de referencia:** Google Trends Colombia, autocompletado de búsqueda, SERP analysis real y patrones de consulta B2B.  
**Regla metodológica (Regla 3.2):** No se inventan cifras de volumen exacto de terceros sin acceso directo a APIs de pago; se clasifican las consultas por nivel de volumen relativo (Alto, Medio, Long-tail), intención de búsqueda y página objetivo en Invends.

---

### 1. Criterios de Selección y Clasificación

Las búsquedas se han categorizado bajo cuatro niveles de intención:

1. **Transaccional Directa (Comercial Alta):** Prospectos con necesidad activa de contratar un proveedor de diseño web, desarrollo de software o branding corporativo. Requieren una página de servicio con alcance, entregables y llamada a la acción inmediata.
2. **Comparativa / Enfoque de Solución (MoFu):** Empresas que evalúan opciones (ej: *"Nuxt vs WordPress"*, *"cuánto cuesta una página web en Colombia"*, *"agencia web vs freelance"*). Requieren contenido pedagógico que las oriente hacia la propuesta técnica de Invends.
3. **Informativa Estratégica (ToFu):** Consultas sobre buenas prácticas, Core Web Vitals, diseño UX/UI o posicionamiento SEO. Generan autoridad y alimentan la herramienta interactiva `/diagnostico`.
4. **Geolocalizada (Bogotá / Colombia):** Consultas que buscan explícitamente un aliado en la capital colombiana o con facturación nacional.
