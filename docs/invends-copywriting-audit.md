# Invends — Auditoría de copywriting (antes → después estratégico)

**Fecha:** 2026-11-05  
**Estrategia aplicada:** claridad de presencia + alcance honesto + oficios integrados.  
**Títulos protegidos:** intactos (verificación automatizada).

---

## 1. Problemas de la comunicación anterior

| Problema | Efecto |
|----------|--------|
| Tagline/proceso centrados en “escuchamos” | Empatía de estribillo; poco valor comercial diferencial |
| Hero abstracto o emocional sin oferta explícita | Visitante tarda en saber qué vende Invends |
| “Experiencias reales” junto a portafolio conceptual | Riesgo de leer casos de cliente donde no los hay |
| Mercado saturado de ROI/IA/transformación | Copiar ese tono = indiferenciación + claims no respaldados |
| Catálogo de 11 servicios sin jerarquía narrativa | Sensación de “todo para todos” |

---

## 2. Decisiones de esta pasada

| Decisión | Justificación |
|----------|---------------|
| Tagline → **Presencia que se entiende.** | Valor defendible; memorable; no lista servicios; no promete resultados |
| Hero → oficios + **alcance claro** | Responde qué hacen + cómo se contrata |
| Reducir “escuchamos / acompañamos” | Brief: empatía por utilidad, no por repetición |
| Portafolio → “método” explícito | Alineado a evidencia `Muestra conceptual` |
| Mantener CTAs conversacionales | Conversión sin presión; contextualizados |
