# Invends — Hero / Header art direction

Placas panorámicas **2700 × 1080** (2.5:1) para el header de inicio.

## Propuestas

| ID | Archivo base | Concepto |
|----|--------------|----------|
| **01** | `invends-hero-01-wavelength` | **Seleccionada.** Onda luminosa violeta–magenta coherente con `AgencyGradient` / `BRAND_WAVE_HEX`. Tercio izquierdo oscuro para tipografía. |
| 02 | `invends-hero-02-prism-craft` | Prisma / cristal y cáusticas: oficio de diseño + código + mensaje como materia. |
| 03 | `invends-hero-03-signal-field` | Campo de señal geométrica: arquitectura digital y presencia estratégica. |
| 04 | `invends-hero-04-atelier-light` | Estudio vacío: luz arquitectónica violeta/magenta, confianza y quietud premium. |

## Formatos por propuesta

- `*-2700x1080.jpg` — master JPEG calidad alta  
- `*.webp` — web optimizado  
- `*.avif` — web optimizado (preferido en `<picture>`)

## Uso

Estas placas son **versiones en imagen** del lenguaje visual del header (onda Invends).  
El hero en vivo sigue usando `AgencyGradient` (WebGL); **no** reemplazan el header del sitio.

Úsalas como asset estático (OG, presentación, mockups, export editorial, etc.).
